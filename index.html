VNPT Invoices Add-in cho Excel

Trình cài đặt trực tuyến (ClickOnce) — tự động cập nhật khi có bản mới.

⬇️ Cài đặt / Cập nhật hoặc mở VNPT.Invoices.AddInV2.vsto
  1. Bấm Cài đặt / Cập nhật ở trên, tải setup.exe rồi chạy.
  2. Nếu Windows cảnh báo SmartScreen: More info → Run anyway (do file chưa ký EV).
  3. Mở Excel — tab VNPT xuất hiện trên ribbon là xong.
  4. Các bản sau tự cập nhật khi mở Excel — không cần tải lại trang này.
Yêu cầu: Windows + Microsoft Office (Excel) 2010 trở lên, .NET Framework 4.x và VSTO Runtime (thường đã kèm Office). Cài theo từng người dùng — không cần quyền Administrator.

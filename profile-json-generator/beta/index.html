Ghi chú các trường
Tài khoản CAdmin: tài khoản đăng nhập link cadmin.
Tài khoản WebService: tài khoản Service tạo ở menu Phân Quyền.
Loại chứng từ: CTT / GTGT / PXK.
Domain: không cần nhập http(s).
Cột mở rộng (tùy chọn): thêm cột ghi vào thẻ Extra, Extra1...Extra11 (cấp hóa đơn) hoặc SP_Extra1/SP_Extra2 (cấp dòng). Kiểu: string/numeric/datetime. Tên cột mặc định là tên thẻ, đổi tên ở "Thứ tự & tên cột".
Cột hóa đơn đặc thù (tùy chọn): chọn loại hóa đơn đặc thù để mẫu Excel bổ sung các cột hàng hóa đặc trưng (VD: Biển kiểm soát).
Chuyển mã sang Unicode: để Unicode (không chuyển mã) cho file bình thường; chọn VNI nếu file dùng font VNI (VD: Coâng ty). Lưu ý: VNI áp cho mọi ô dữ liệu; file lẫn ô Unicode gõ tay (VD: Công ty Hoàng Long) có thể bị đổi sai, nên để cả file một kiểu. Tiêu đề cột không được chuyển: khai tên cột đúng như đang thấy trong file.
Thứ tự & tên cột (tùy chọn): kéo-thả để đổi thứ tự cột trên mẫu Excel sinh ra; khai tên thay thế khi file của khách đặt tên cột khác mẫu (VD: xuất từ phần mềm khác), dòng tiêu đề, công thức tính cột (giống Excel) và giá trị mặc định khi ô trống.

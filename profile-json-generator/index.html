Ghi chú các trường
Tài khoản CAdmin: tài khoản đăng nhập link cadmin.
Tài khoản WebService: tài khoản Service tạo ở menu Phân Quyền.
Loại chứng từ: CTT / GTGT / PXK.
Domain: không cần nhập http(s).
Cột mở rộng (tùy chọn): map cột Excel → thẻ Extra1…Extra11 (cấp hóa đơn) hoặc SP_Extra1/SP_Extra2 (cấp dòng). Kiểu: string/numeric/datetime.
Cột hóa đơn đặc thù (tùy chọn): HDDThu, TCHDon, TTHHDTrung — add-in tự lấy header/ghi chú theo field.
